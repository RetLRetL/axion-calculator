# Axion Spectrum Calculation 2.0

## 1. Общая информация

Программа предназначена для расчёта спектра аксионов, возникающих при взаимодействии гамма-квантов с веществом.

**Входные данные:**
- ROOT-гистограммы спектров гамма-квантов:
  - `Sp_gamma_start`
  - `Sp_gamma_end`
- Табличные сечения XCOM для разных элементов
- Определённая смесь элементов (`mixture`)

**Выходные данные:**
- ROOT-файл с рассчитанными спектрами аксионов:
  - `alp_start`
  - `alp_end`

Программа поддерживает два режима расчёта:
- **Интегральный** (суммирование по гамма-энергиям)
- **Приближённая формула** (`USE_APPROX = true`) без интеграла

## 2. Настройки (`settings.h`)

Файл `settings.h` задаёт поведение программы и ключевые параметры.

### 2.1 Основные настройки

| Параметр       | Тип         | Значение по умолчанию       | Назначение |
|----------------|------------|----------------------------|------------|
| `USE_APPROX`   | bool       | `false`                    | `false` — интеграл, `true` — приближённая формула |
| `USE_CUTS`     | bool       | `true`                     | Включение защиты от NaN/inf и слишком больших значений |
| `MIN_VAL`      | double     | `1e-30`                    | Минимальное значение для защиты от деления на ноль |
| `DATA_DIR`     | const char*| `"."`                       | Директория с входными и выходными ROOT-файлами |

### 2.2 Диапазон гамма-энергий

### До версии 2.0:

Задаётся в `main.cpp`:

```cpp
const double Egamma_max = 10.0;  // верхняя граница гамма-энергии (МэВ)
const double Egamma_min = (2.0 * me * ma + ma*ma) / (2.0 * me); // нижняя граница гамма-энергии
```
### В версии 2.0:

Задан в `main.cpp` в соответствии с физикой:

```cpp
double Egamma_min_dyn = (-0.5 * ma*ma + Ea * mU) / denom_plus;
double Egamma_max_dyn = (-0.5 * ma*ma + Ea * mU) / denom_minus;
```

**Применение:**

```cpp
if (Eg < Egamma_min || Eg > Egamma_max) continue;
```

## 3. База данных XCOM (`database.h` / `database.cpp`)

### 3.1 Структура данных

* `E_data[element]` — массив энергий (МэВ)
* `S_data[element]` — массив сечений (barn)

### 3.2 Загрузка данных

* Функция `load_XCOM()` заполняет таблицы `E_data` и `S_data` для каждого элемента.
* Массив `E_data[element]` должен быть строго возрастающим.
* Длина массивов `E_data[element]` и `S_data[element]` должна совпадать.
* Имена элементов должны совпадать с названиями в `mixture`.

### 3.3 Добавление нового элемента

```cpp
E_data["Fe"] = {0.001, 0.002, ...};
S_data["Fe"] = {1234, 567, ...};
```

---

## 4. Смесь элементов (`mixture`)

Смесь задаётся через функцию `init_mixture()`.

**Структура элемента:**

* `name` — имя элемента (совпадает с XCOM)
* `n` — концентрация (1/см³)
* `A` — массовое число

**Пример:**

```cpp
mixture = {
    {"O", 2.582e22, 16},
    {"H", 2.516e22, 1},
    {"U", 6.196e21, 238},
    {"Zr", 5.634e21, 91},
    {"U", 2.132e20, 235},
    {"Pu", 2.453e19, 239},
    {"Gd", 1.528e19, 157},
    {"Pu", 7.237e18, 240}
};
```

**Правила:**

* `name` должен совпадать с ключом в XCOM
* Можно добавлять или удалять элементы
* Концентрации `n` задаются в физических единицах (1/см³)

## 5. Физический смысл переменных в `main.cpp`

| Переменная       | Описание                                                                  |
| ---------------- | ------------------------------------------------------------------------- |
| `gagg`           | Константа взаимодействия аксион-гамма                                     |
| `Z`              | Заряд вещества (например, для U = 92)                                     |
| `me`             | Масса электрона (МэВ)                                                     |
| `ma`             | Масса аксиона (МэВ)                                                       |
| `alpha`          | Константа: `111 * Z^(-1/3) * me`                                          |
| `Egamma_min/max` | Границы гамма-энергии для интеграла или приближённого расчёта             |

## 6. Работа с ROOT-файлами

**Входные файлы:**

* `DATA_DIR/Gamma_sp.root`

**Выходной файл:**

* `DATA_DIR/alp_result.root`

**Гистограммы:**

* `Sp_gamma_start` и `Sp_gamma_end` — входные спектры гамма-квантов
* `alp_start` и `alp_end` — рассчитанные спектры аксионов

## 8. Основные функции

### 8.1 `interpolate()`

Линейная интерполяция сечений по энергии:

```cpp
double interpolate(const vector<double>& E, const vector<double>& S, double x);
```

### 8.2 `load_XCOM()`

Загружает массивы `E_data` и `S_data` для всех элементов.

### 8.3 `init_mixture()`

Инициализация смеси элементов с концентрациями и массовыми числами.

### 8.4 `sigma_SM_mix(E)`

Эффективное сечение смеси:

```cpp
double sigma_SM_mix(double E);
```

### 8.5 Основной цикл расчёта

* Проходит по бинам входного спектра
* Вычисляет интеграл для каждого бина:
  - `USE_APPROX = true` — приближённая формула
  - `USE_APPROX = false`  — численный интеграл по энергии гамма-кванта
  - `USE_CUTS` — применяются защиты
* Результаты записываются в `alp_start` и `alp_end`

## 9. Настройка и изменение параметров

1. **Диапазон гамма-энергий:** `Egamma_min` и `Egamma_max` в `main.cpp`

4. **Смесь элементов:** `init_mixture()` в `database.cpp`

## 10. Terminal Output and Debug Messages

1. **Fallback usage:** `[FALLBACK USED] Ea=... Eg_mid=... width=...` в `main.cpp`
   Сообщение выводится, когда ни один бин гистограммы не попадает в интегральный диапазон. Используется приближение с серединой диапазона для интеграла.

2. **Completion message:** `Done!` в `main.cpp`
   Печатается после успешного завершения программы и записи выходного ROOT-файла.
